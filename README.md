# Skin-Cancer-Detection
 The dataset used for this project is the Skin Cancer Classification dataset obtained from Kaggle. It contains 16,831 high-quality dermoscopic skin lesion images collected for the detection and classification of different types of skin cancer. The images are categorized into seven skin lesion classes: Actinic Keratosis and Intraepithelial Carcinoma (AKIEC), Basal Cell Carcinoma (BCC), Benign Keratosis-like Lesions (BKL), Dermatofibroma (DF), Melanoma (MEL), Melanocytic Nevi (NV), and Vascular Lesions (VASC). The dataset is already divided into training, validation, and testing sets, making it suitable for developing and evaluating deep learning models for automated skin cancer detection.
## Dataset Link: https://www.kaggle.com/datasets/murtozalikhon/skin-cancer-classification
